LESS HUNTING. MORE FINDING.

An email archive you can actually use.

01 / READ

Open your exports.

Import EML messages or MBOX archives, including folders of files. HTML opens automatically when available, with a plain-text fallback and a green Next button.

02 / FIND

Search with purpose.

Combine from:, to:, cc:, subject:, body:, and has:attachment. Search includes HTML-only message text and attachment filenames.

03 / PREVIEW

See what came with it.

Preview PDFs, photos, audio, and video. Read extracted text from DOCX and supported DOC files. Download the original attachment whenever you need it.

04 / ORGANIZE

Make room for what matters.

Browse year/month groups, select a date range, and export attachments into folders. Select multiple messages or attachments for deletion, then advance to the next email.

YOUR FIRST FIVE MINUTES

Keep it local.
Keep it simple.

Once the viewer opens, choose Open managed folder to work with original email files, or import copies to browse.

  1. Choose your archive. Open .eml, .mbox, or .mbx exports. Files stay on your computer.
  2. Find a message. Try from:ada has:attachment, or filter by dates and select the matching results.
  3. Save what you need. Export attachments to a chosen folder, organized by year, month, and email.
  4. Close when you’re finished. Keep the launcher’s terminal open while using Postbox. Press Ctrl + C there to stop it.

A few useful details.

Which browser should I use?

Chrome or Edge supports choosing folders and changing original files. Other modern browsers can read imported copies, delete from the session, and export attachments as a ZIP. PDF and media previews depend on your browser and codecs.

What does Delete this email do?

It follows the selected deletion mode. Original-file deletion removes an EML file or rewrites its MBOX archive; embedded attachments go with the email. Attachment-only deletion rewrites the source email. Session-only deletion leaves files on disk unchanged. Confirmation and original-file checks happen first; separately exported files are never removed. Successful deletion opens the next remaining message. Deletion cannot be undone in Postbox.

Does it upload my email or load trackers?

The app uses a loopback server on your computer. It has no external email service, analytics, or account. Message HTML is sanitized and isolated; scripts, remote images, and navigation are blocked. MBOX parsing briefly uses a local temporary file, which is removed after parsing.

What are the limits?

Each imported file is limited to 100 MB, and the archive is held in memory. Split larger MBOX exports before importing. MSG and PST need conversion to EML or MBOX first. Word previews show text rather than page layout; encrypted and unsupported document variants require another application. Attached-file contents are not indexed by email search.

Has it been tested on both operating systems?

The bundled Linux runtime, MIME/MBOX handling, and organizer have automated checks. Navigation and file actions have DOM regression tests with simulated file handles. Windows package contents are verified, but native Windows execution has not yet been tested.
